# Credits

worm_instruments_assets ships work by these authors. Each is credited again in worm_instruments' install notes.

## Sounds

Every recorded sample set, with its source and licence, is listed here when it is added (from Phase 2). Only sets whose
licence allows selling them inside a script are used: CC0 (VCSL, VSCO 2 CE, Karoryfer Big Rusty Drums) and the
University of Iowa Musical Instrument Samples ("may be used for any projects, without restrictions"). The synthesised
instruments are made by the build script in `Source/Sounds/` (Wormhole Studios).

## Props

Every prop is modelled for this script (Wormhole Studios); the game's own models are read only as a reference for size
and proportion. Each prop's source is kept in `Source/<prop>/` when it is added (from Phase 3).
